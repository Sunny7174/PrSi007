## 🗺️ 1-Week Roadmap: Crack the ExxonMobil Junior Software Developer Interview (Bengaluru)

> **Role:** Junior Software Developer — ExxonMobil, Bengaluru  
> **Difficulty (as reported by insiders):** Basic to Medium  
> **Goal:** Crack the technical interview in 7 days

---

### 📌 What ExxonMobil Typically Tests (Junior Level)
- Data Structures & Algorithms (basic–medium)
- Object-Oriented Programming (OOP) concepts
- Core Java / C++ / Python fundamentals
- SQL & Database basics
- Web fundamentals (HTML, CSS, JS, REST APIs)
- Problem-solving aptitude & logical reasoning
- Basic System Design concepts
- Behavioural / HR round

---

### 📅 Day 1 — DSA Foundations: Arrays, Strings & Complexity

**Topics:**
- Big-O notation (Time & Space complexity)
- Arrays: traversal, two-pointer, sliding window
- Strings: reversals, palindromes, anagrams, frequency maps
- Basic sorting: Bubble, Selection, Insertion (understand, don't memorise)

**Practice (LeetCode / GFG — Easy level):**
- Two Sum, Best Time to Buy and Sell Stock
- Valid Anagram, Longest Substring Without Repeating Characters
- Move Zeroes, Rotate Array

**Resource:** [NeetCode Arrays & Hashing](https://neetcode.io/) | GFG Arrays section

---

### 📅 Day 2 — DSA: Linked Lists, Stacks, Queues & Recursion

**Topics:**
- Singly & Doubly Linked Lists: insert, delete, reverse
- Stack (LIFO) & Queue (FIFO) — array and linked-list implementations
- Recursion basics + Factorial, Fibonacci

**Practice:**
- Reverse a Linked List, Detect Cycle in Linked List
- Valid Parentheses (stack), Min Stack
- Climbing Stairs (intro to DP via recursion)

**Resource:** GFG Linked Lists | LeetCode Top Interview 150

---

### 📅 Day 3 — DSA: Trees, Searching & Sorting

**Topics:**
- Binary Trees: inorder, preorder, postorder traversal
- Binary Search Trees: insert, search, delete
- Binary Search algorithm (O(log n))
- Merge Sort & Quick Sort (concept + complexity)
- Hashing basics (HashMap / HashSet)

**Practice:**
- Maximum Depth of Binary Tree, Inorder Traversal
- Binary Search (classic), Search in Rotated Sorted Array
- Two Sum using HashMap

---

### 📅 Day 4 — OOP Concepts & Core Language Fundamentals

**Topics (focus on Java or C++ — whichever you are stronger in):**
- 4 Pillars: Encapsulation, Inheritance, Polymorphism, Abstraction
- Interfaces vs Abstract Classes
- Constructors, `this` keyword, `static` vs `instance`
- Exception Handling (`try-catch-finally`, custom exceptions)
- Collections Framework (Java): ArrayList, HashMap, HashSet, LinkedList
- Memory management: Stack vs Heap, Garbage Collection

**Practice:**
- Write a class hierarchy (e.g., Shape → Circle, Rectangle)
- Implement a generic Stack using OOP
- Solve 5 GFG OOP interview questions

**Resource:** [Java OOP - Programiz](https://www.programiz.com/java-programming/oop) | GFG OOP section

---

### 📅 Day 5 — SQL & Database Fundamentals

**Topics:**
- DDL vs DML vs DCL commands
- SELECT with WHERE, GROUP BY, HAVING, ORDER BY
- JOINs: INNER, LEFT, RIGHT, FULL OUTER
- Subqueries & nested queries
- Primary Key, Foreign Key, Unique, Not Null constraints
- Normalization (1NF, 2NF, 3NF — conceptual understanding)
- Indexes and why they matter

**Practice:**
- LeetCode SQL 50 study plan (Easy problems: Combine Two Tables, Second Highest Salary, Employees Earning More Than Their Managers, Duplicate Emails, Customers Who Never Order)
- Write queries on a sample Employee / Department schema

**Resource:** [W3Schools SQL](https://www.w3schools.com/sql/) | LeetCode SQL 50

---

### 📅 Day 6 — Web Technologies + Basic System Design + APIs

**Topics:**
- How the web works: HTTP, DNS, Client-Server model
- REST API concepts: GET, POST, PUT, DELETE, status codes
- HTML/CSS fundamentals (semantic tags, box model, flexbox basics)
- JavaScript: DOM, event listeners, fetch API, Promises/async-await
- Node.js basics: Express setup, routing, middleware
- Basic System Design: what is scalability, load balancer, database, cache

**Practice:**
- Build or review a simple CRUD app with Node.js + MySQL
- Explain your past projects in terms of architecture
- Read about: URL shortener design, design a simple login system

**Resource:** [CS Fundamentals - roadmap.sh](https://roadmap.sh/backend) | Node.js official docs

---

### 📅 Day 7 — Full Revision + Mock Interview + Behavioural Prep

**Morning — Revision Sprint (3–4 hrs):**
- Revise Big-O, top 10 DSA patterns
- Revise OOP pillars with code examples
- Quick SQL query revision (JOINs + subqueries)
- Review your own projects — be ready to explain every line

**Afternoon — Mock Interview (2 hrs):**
- Do a timed mock on Pramp / Interviewing.io / a friend
- Solve 3 random LeetCode Easy-Medium problems under time pressure
- Practice explaining your thought process out loud (think-aloud technique)

**Evening — Behavioural & HR Prep (1–2 hrs):**
- Prepare STAR answers for: Tell me about yourself, Why ExxonMobil, Your strengths/weaknesses, A time you solved a challenging problem
- Research ExxonMobil: their tech initiatives, sustainability goals, India operations

---

### ⚡ Quick Tips for Interview Day
| Tip | Detail |
|---|---|
| **Think Aloud** | Always verbalise your approach before coding |
| **Clarify First** | Ask clarifying questions before jumping to code |
| **Edge Cases** | Always mention null/empty/negative edge cases |
| **Time/Space** | Always state the complexity of your solution |
| **Projects** | Know your resume projects inside-out; expect deep dives |
| **Attitude** | Be eager, positive, and show willingness to learn |
